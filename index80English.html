Image Import

Imported images are compressed to WebP in supported browsers, or JPEG when WebP conversion is unavailable, and stored in the HTML with Base64 data limited to 18,000 characters per image. Symbols such as brackets that may cause problems in Markdown are automatically removed from image file names. Insert an image in the text with “[Insert Image](filename)”.

    Display Size

    Choose the overall text size for the viewer. Medium is the current standard size.

    Fonts to Use

    Enabled fonts are tried from left to right. Fonts unavailable on the device and fonts set to OFF are skipped. ON/OFF settings are kept after reloading.

    Save Options

    Choose a save method.

    Standard Save

    Downloads the full document site itself. It is not affected by future updates.

    Compressed Save

    Compresses and downloads the full document site. It is decompressed in the browser when opened and is not affected by future updates.

    Reduced-Size Save

    Downloads a lightweight HTML file that opens the document through this hosted site. Because it depends on the hosted page, future updates may affect it.
    Available compression methods are compared in supported browsers, and the smallest result is used.
    If the compressed Base64 data exceeds 8,000 characters, some browsers may not be able to open the resulting long URL.

    Save as URL

    Compresses the current content and stores it inside the URL. Opening the copied URL restores the content on this page.
