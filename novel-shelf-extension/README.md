# 小説棚 - 作品別JSON保存＆閲覧出力 Chrome拡張

閲覧中の小説ページをサイト単位の作品ごとに自動保存し、出力パネルから次の2種類を出力するMV3 Chrome拡張です。

- `サイト名_小説名.json`：作品情報とページ本文
- `サイト名_小説名_閲覧.html`：ライトテーマ固定のオフライン閲覧サイト

## 使い方

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から、このフォルダを選びます。
4. 小説ページを開いて読み進めます。対応する本文を検出すると、自動で小説棚へ保存します。
5. ツールバーの拡張機能アイコン、または `Ctrl+Shift+Y` で小説棚のサイドパネルを開きます。
6. 保存した小説の「閲覧サイト」または「JSON」を押して出力します。

## ローカルJSONフォルダ

Chrome拡張のインストール先はChromeの仕様上、拡張機能から書き込みできません。そのため、通常は `chrome.storage.local` に保存します。

パネルの「保存フォルダを選ぶ」でユーザーが書き込み先を選択すると、以後はそのフォルダへサイト単位の作品別JSONを自動同期します。同じサイト・同じ作品の再取得時は既存JSONを新しい内容へ更新します。拡張機能を削除・再インストールしても残したいデータは、最初に保存フォルダを設定するか、パネルからJSONを出力してください。

## 対応サイトと取得方法

次の主要サイトだけを取得対象にしています。対象外のサイトにはコンテンツスクリプトを注入せず、本文らしさによる推測取得も行いません。

- 小説家になろう系 (`syosetu.com`)
- ハーメルン (`syosetu.org`)
- カクヨム (`kakuyomu.jp`)
- アルファポリス (`alphapolis.co.jp`)
- pixiv小説 (`pixiv.net/novel/`)

各サイトは本文セレクターを優先し、取得できない場合は本文らしい要素や段落の集合も候補にして取得を試みます。ページ表示や再取得を開始した後、1秒後・1.5秒後・2秒後・3秒後・5秒後・8秒後・13秒後の計7回取得します。最初は短い間隔で試し、後になるほど間隔を広げます。2回目以降は同じページでも保存側へ再送し、新しく読み込まれた本文で上書きします。それでも取得できない場合は、対応サイトの小説ページを表示した状態でパネルの「現在のページを取得」を押してください。

解析した本文・ページ要素・文書全体からページ情報を探し、`12/574`、`1 / 131`、`12ページ目` などの先頭数字を各ページの `pageNumberInfo` としてJSONに保存します。出力時は `pageNumberInfo` を最優先にしてページを並べます。ハーメルンの `No.0003` などはページ名として保存しますが、ソートの判断基準には使用しません。ページ情報が見つからないページは、取得時の仮番号を使用します。同じURLのページは新しい本文へ更新され、URLが変わっても同じサイトでページ番号やタイトルが一致する場合は同じページとして更新を試みます。作品の保存キーはサイト単位なので、別サイトの同名作品が混ざりません。

ハーメルンのタイトルが `ページ名 - 小説名 - ハーメルン` の形式の場合は、後ろから2個目のハイフン以降を小説名、手前をページ名として保存します。さらに、`<a href="./">小説名</a>` 形式の作品リンクも小説名の候補として優先取得します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | Chrome拡張の定義（Manifest V3） |
| `background.js` | 作品別保存、設定、パネルとの連携 |
| `content-script.js` | 表示中ページの小説タイトル・本文・URLの検出 |
| `panel.html` / `panel.css` / `panel.js` | サイドパネルの一覧、出力、JSON同期 |
| `reader-template.js` | オフライン閲覧HTMLの生成 |

## 注意

本文取得はページに表示されているテキストを対象にします。ログインが必要な本文、iframe内の本文、サイト独自の仮想スクロールなどは取得できない場合があります。また、保存した本文は個人利用の範囲で扱い、各サイトの利用規約・著作権に従ってください。
